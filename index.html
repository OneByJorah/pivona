pivona

Professional router dashboard for Raspberry Pi — manage routing, firewall, DHCP, DNS, VPN tunnels, and real-time traffic monitoring from a sleek web interface.

🚀 Get Started 📦 View on GitHub
⚡ Capabilities

Enterprise-Grade Routing
on a Raspberry Pi

Full-featured network management dashboard with real-time monitoring, multi-VPN support, and system oversight.

📡

Routing Management

Configure and monitor network routing rules, NAT, and port forwarding with iptables/nftables.

🔒

Firewall Control

Manage iptables and nftables rules through an intuitive interface with preset profiles.

🌐

DHCP & DNS

Built-in DHCP server with lease management and local DNS resolution with forwarding.

🔐

Multi-VPN Gateway

WireGuard, Cloudflare WARP, NordVPN, NetBird, Mesh-VPN, and UniFi Teleport — all in one dashboard.

📊

Traffic Monitoring

Real-time bandwidth graphs (live 30-min view), historical traffic (24h/3d/7d), and per-second throughput.

⚡

Speed Test

Built-in internet speed test with history tracking — measure download and upload from the dashboard.

🌡️

System Health

CPU, memory, disk, temperature monitoring with visual gauges and historical charts.

📱

Client Management

View all connected DHCP clients with hostname, IP, and MAC address details.

🏗️ Architecture

Route Flow

How network traffic flows through pivona from internet to LAN devices, with all management layers.

🚀 Quick Start

Get Running in Minutes

Deploy on a Raspberry Pi 4/5 or test locally with Docker.

🐧 Raspberry Pi

# Clone and run
git clone https://github.com/OneByJorah/pivona.git
cd pivona
sudo bash start.sh

# Open http://localhost:5000

🐳 Docker (Testing)

docker compose up -d
# Open http://localhost:5000
